# Mr.Bricolage Scraper API – code examples

Examples for every Mr.Bricolage endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/suggest.sh`](curl/suggest.sh) | `bash suggest.sh` |
| PHP | [`php/suggest.php`](php/suggest.php) | `php suggest.php` |
| C# | [`csharp/Suggest.cs`](csharp/Suggest.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/suggest.go`](go/suggest.go) | `go run suggest.go` |
| Java | [`java/SuggestExample.java`](java/SuggestExample.java) | `java SuggestExample.java` |
| Ruby | [`ruby/suggest.rb`](ruby/suggest.rb) | `ruby suggest.rb` |
| Node.js | [`nodejs/suggest.mjs`](nodejs/suggest.mjs) | `node suggest.mjs` |
